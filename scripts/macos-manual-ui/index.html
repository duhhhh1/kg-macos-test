从现有工作台进入本轮界面，访问凭据仅用于这台临时 Mac。

按顺序完成

  1. 如仍在入口页，填写 https://ivpn.hit.edu.cn 并点击 OK。
  2. 主题提示点击 Later；同意条款后点击 Log In。
  3. 在 Safari 的学校认证页完成本人登录及实际要求的验证。
  4. 点击程序坞中的 aTrust 图标，查看是否显示已连接。
  5. 点击下方检查校园网连接，连通后点击登录完成，继续测试。

辅助输入

也可以先点击远程输入框，再在这里输入文字并发送。内容仅传给本轮 Mac，发送后立即清空。

不要在其他地方重新输入 GitHub token 或 SSH 私钥。本页面只需操作学校正常登录界面。原生测试开始后关闭远程输入，结果回传原工作台。
